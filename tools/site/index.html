What's new over the arcade

  • Straight to the game. No boot screen, always free play (or the arcade's boot, coins and credits, if you like).
  • 3D upscaled up to 6x, the Model 3's look kept crisp.
  • Widescreen and ultrawide. The fights see more to the sides, and the stages' backgrounds carry on from the game's own panoramas.
  • Smooth motion up to 120 fps.
  • The 3D on your GPU (Metal, Vulkan or Direct3D 12), checked against the CPU's picture as the game starts.
  • Antialiasing, and scanline or CRT screen filters.
  • An options menu for display, sound (music, effects and voices apart), controls and the arcade's own settings: difficulty, rounds to win, energy and country, and its service menu. No test mode needed.
  • Keyboard or controller, two players. Every button remappable, and the menu on any pad (L3 + R3, or the touchpad).
  • Keeps up by itself: if your computer can't, it lowers the quality, and gives it back once it can.

You need

MAME's "vf3" set (Revision D), as vf3.zip. Team Battle (vf3tb) isn't supported yet.

Nothing from the game is included or shared. Each file is checked by CRC, and the code is recompiled on your machine when it starts.

Where it goes

Mac and Windows: it asks for it the first time and keeps a copy.

Steam Deck: put it in VirtuaFighter3/roms.

Windows 10 or 11 (64-bit)

  1. Unzip the VirtuaFighter3 folder anywhere (not inside Program Files).
  2. Run VirtuaFighter3.exe. It isn't signed, so SmartScreen may warn: More info > Run anyway.
  3. Choose your vf3.zip when it asks.

Mac (macOS 11+, Apple silicon or Intel)

  1. Unzip and move Virtua Fighter 3 Recomp to Applications.
  2. It isn't signed, so macOS blocks it the first time. Open it once, close the message, then System Settings > Privacy & Security > Open Anyway.
  3. Choose your vf3.zip when it asks.

Steam Deck

  1. Copy the download to the Deck and unpack it there (Desktop Mode: right-click > Extract > Extract archive here).
  2. Put vf3.zip in VirtuaFighter3/roms.
  3. Desktop Mode: Steam > Add a Non-Steam Game, pick the vf3 file (file type: All files). In its Properties, set Start In to the VirtuaFighter3 folder and turn off any forced compatibility tool (Proton).
  4. Play it from Game Mode with the default gamepad layout.

Portable: a file named portable.txt next to the program (Mac: next to the app), or in the folder above it, keeps everything in its folder, the copy of vf3.zip too, and nothing in your user data folder.

Your own ROM folder (e.g. Batocera's /userdata/roms/ports/vf3): start it with --roms <folder>, set VF3_ROMS, or add roms_folder = <folder> to settings.ini. The game looks for vf3.zip there first and only reads it; log.txt says which folder it used. See the README.

  • It's an alpha: if something looks or plays differently from the arcade, say so in GitHub Issues, with the log.txt from the game's data folder.
  • Shun's stage water is the game's own low-resolution 2D art, so it's soft up close.
  • Direct3D 12 hasn't been tried on real Windows hardware yet. If it draws wrong, the game switches to Vulkan, or the CPU.

A fan-made static recompilation of Virtua Fighter 3 (Sega Model 3, 1996): the arcade's own code is translated to native code on your machine, and the rest of the board is rebuilt around it. No ROMs or game files are included: you need your own copy. Not affiliated with or endorsed by SEGA. Unsigned: run it at your own risk.

Made with the help of AI coding tools. Every build is checked frame by frame against the arcade (via Supermodel).
